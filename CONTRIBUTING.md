# Contributing

Clavis is source-available, not open source. Code is licensed under the PolyForm Noncommercial
License 1.0.0 (see `LICENSE`) and learning content under CC BY-NC 4.0 (see `LICENSE-CONTENT`). The
maintainer keeps the right to use and relicense the project commercially, so every contributor
agrees to the [Contributor Licence Agreement](CLA.md) first.

## Before you open a pull request

1. Read [`CLA.md`](CLA.md). If you do not agree, please do not submit a pull request.
2. Read [`CLAUDE.md`](CLAUDE.md) for the commands, package boundaries and conventions.
3. Work on one plan task at a time (`docs/implementation-plan.md`).
4. Run `pnpm check` locally. It must pass before the pull request is opened.
5. Tick the CLA box in the pull request template. A pull request without it will not be merged.

## Third-party code and content

Do not copy code or content you do not have the right to relicense. No GPL or AGPL dependencies.
Every new dependency or content source needs an entry in `docs/licences.md`, and dependencies are
pinned to exact versions.
